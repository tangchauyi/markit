# Mark it! 宣传短片 · 分镜脚本 v4

- **版本**：v4（痛点定稿：打断偷走你的事 + 前后对照式剧情）
- **定位**：约 65 秒竖版 9:16，小红书 / 朋友圈发布
- **画面比例**：9:16（看板本体 360×640 = 9:16，满屏演出）
- **配音**：不带配音，字幕独立成立；口播稿按 4.5 字/秒预留时间码
- **平台**：仅 Mac
- **叙事主线**：**「被偷走的一天」vs「Mark it 的一天」**——前半段完整还原打断剧情（忘了），后半段同样剧情重演一遍（这次两秒记下，没丢）。前后对照，看板就是那条分界线
- **成片目标**：MP4 1080×1920

---

## v4 核心改动

1. **痛点升级为剧情**：v3 的痛点是氛围铺陈，v4 是一段完整的小剧场——「专注分析 → 老板掐断 → 同事再断 → 回神一片空白 → 第二天被问结果」。有起承转合，观众是来追剧的
2. **前后对照结构**：后半段用同样剧情重演一遍，只是这次被打断的瞬间两秒记进了看板。产品不用解说，对照自己说话
3. 题眼从「记了 = 忘了」升级为「**被打断的事，就是这样被偷走的，而且你根本不会发现**」——更扎，因为遗忘是无感的

## 口播全文（连贯稿，约 300 字，4.5 字/秒 ≈ 66s）

> 你正沉浸在一份数据分析里，思路特别顺。
> 突然，老板一句话把思路掐断了：下午三点前，渠道数据发我。你回了个好的，切过去干活。
> 刚干完老板的，同事又来：帮我查个库存。行，又去帮忙。
> 等你回到自己工位，屏幕还是那份数据，脑子里已经一片空白：我刚才，做到哪了？
> 第二天同事来问结果，你才发现——那件事，从被掐断那一刻起，就没了。
> 不是记性差。被打断的事，就是这样被偷走的——而且你根本不会发现。
> Mark it 把看板钉死在屏幕角落。打断来的那一刻，两秒记下；干完别人的活，抬头——它还在。
> 同样的一天再过一遍：老板的事，双击 P0 就地记下；同事的事，回车落进随手记。干完别人的活，抬头——看板里两条都在，一件都丢不了。
> 事情在变，长按一拖，轻重缓急随时改判，松手即落。
> 做完打勾，不想干沉底，手滑？撤销还在。
> 要投屏开会？收成一颗胶囊，安静待在角落。
> 晚上抬头，今天全清。日历还替你记着，你干过的每一天。
> 无账号、无联网、无埋点，笔记只存在你 Mac 上。GitHub 搜 markit，拖进 Applications，明天开工就用。
