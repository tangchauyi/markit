## 口播全文（连贯稿，共约 200 字，语速 4.5 字/秒）

> 你的待办清单，是不是开了三个应用，最后还是记在桌面便签上？
> 所以我做了 Mark it，一块钉在屏幕角落的四象限看板。
> 重要紧急四个象限，随手记一条，一眼看清今天先做什么。
> 记一条多快？点输入框，打字，回车，完事。
> 想直接记进某个分区？双击它。剪贴板里的东西？悬停分区按一下 Command V。
> 长按一拖，挪到别的象限、调先后顺序，都是松手即落。
> 做完了打勾，不想干了沉底，删错了？撤销还在。
> 看板碍事？收成一颗胶囊，四色圆点加角标，戳一下就回来。
> 它还记得你每天干过什么，点日历就能回看。
> 无账号无云同步无埋点，你的笔记只存在你自己的电脑上。Mac 和 Windows 都能用。
