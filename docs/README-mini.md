# Mark it!（极简版说明）

**四象限便签看板，钉在桌面角落。**

- 📌 四个分区：P0 重要且紧急 / P1 重要不紧急 / P2 不重要但紧急 / P3 随手记
- ⌨️ 底部输入框回车即记；双击分区空白就地记；悬停分区 ⌘V / Ctrl+V 直接粘贴成笔记
- ✏️ 双击笔记改字，点别处即保存
- 🖐 长按拖动排序，拖到别的分区还能换象限
- ✅ 完成 / 不干了 / 恢复三态，日历按天回顾
- 🌗 跟随系统深浅色；数据全在本地，不联网不上报

**安装**：[Releases](https://github.com/tangchauyi/markit/releases/latest) 下载
- Windows：`Setup.exe` 双击安装
- macOS（Apple 芯片）：`.dmg` 拖入 Applications

首次启动如有安全提示（未购买签名证书），Windows 选「仍要运行」，Mac 右键「打开」即可。
