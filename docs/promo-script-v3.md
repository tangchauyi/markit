## 口播全文（连贯稿，约 285 字，4.5 字/秒 ≈ 63s）

> 上班的时候，事情是这样飞过来的：群里随口一句下午同步下，你回了个收到，然后就没有然后了。
> 不是记性差——是你写下来那一刻，它就沉底了。记了，等于忘了。
> Mark it 把看板钉死在屏幕角落，写下来的，抬头就看得见。
> 四个象限分轻重缓急，今天先干哪件，一眼就有答案。
> 早上开工，先把乱飞的事全丢进去：九点半站会、周四周报、帮同事订会议室——打字，回车，完事。
> 真正要命的，双击 P0 直接记：三点客户评审。刚复制的需求文档？悬停，按一下 Command V，整段落进看板。
> 白天事情在变：站会结束了，拖去快速处理；发版提前了，拖回 P0 置顶。轻重缓急，随时改判，松手即落。
> 干完一条打一个勾，是真爽。不想干的那条，沉底变灰。手滑删错？撤销还在。
> 开会要投屏？收成一颗胶囊，安静待在角落。
> 晚上加完班抬头，今天全清了。点开日历，你干过的每一天，它都替你记着。
> 无账号、无联网、无埋点，笔记只存在你 Mac 上。GitHub 搜 markit，拖进 Applications，明天开工就用。
