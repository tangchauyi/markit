# Mark it! — plan for it

> 常驻桌面角落的四象限便签看板：随手记，一眼看清今天该先做什么。

无账号、无登录、无云同步——你的每一条笔记都只存在你自己的电脑上。

## 它是什么

一块默认 360×640 的迷你看板（macOS 可拖边缩放，自定义尺寸会被记住），按艾森豪威尔矩阵分成四个分区，钉在屏幕角落：

| 分区 | 含义 |
| --- | --- |
| **P0** | 重要且紧急 —— 现在就做 |
| **P1** | 重要但不紧急 —— 排进日程 |
| **P2** | 不重要但紧急 —— 快速处理 |
| **P3** | 不重要且不紧急 —— 随手记 |

不需要时收成一颗迷你胶囊（4 色圆点 + 待办数角标），点一下展开回来。

## 下载安装

到 [Releases](https://github.com/tangchauyi/markit/releases/latest) 页下载最新版：

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| Windows x64 | `Mark-it-Setup-x.x.x.exe` | 双击一键安装（无需管理员权限） |
| macOS Apple Silicon | `Mark-it-x.x.x-arm64.dmg` | 打开镜像，拖入 Applications |

> 本项目未购买代码签名证书，首次运行可能触发系统安全提示：
> - **Windows SmartScreen**：点「更多信息 → 仍要运行」
> - **macOS**：右键应用 →「打开」（或系统设置中允许）

## 快速上手：30 秒记下第一条

1. 启动应用，看板出现在屏幕右下角（位置会记住）
2. 点击底部输入框，打字，**回车** —— 落在 P3 分区
3. 想让它进别的分区？双击**那个分区的空白处**直接就地输入，自动带上分区优先级
4. 在电脑任意处复制了文字？把鼠标**悬停在目标分区上按 ⌘V / Ctrl+V**，直接落一条

## 交互速查

| 你想做什么 | 怎么做 |
| --- | --- |
| 记一条（默认 P3） | 底部输入框打字 + 回车 |
| 记到指定分区 | 双击分区空白处，就地输入 |
| 粘贴成笔记 | 悬停分区 + ⌘V / Ctrl+V |
| 改一条的字 | **双击笔记条**，或 hover 点 ✎，改完点别处即保存（Esc 取消） |
| 调整先后次序 | **长按**笔记条约半秒，上下拖到想要的位置松手 |
| 移到别的分区 | 长按后**拖到目标分区**，落在你松手的位置（那条的上/下方） |
| 标记完成 | hover 笔记条，点 ✓ |
| 不想干了 | hover 笔记条，点 ⊘（沉到分区底部，灰色残影） |
| 标错了想恢复 | hover，点 ↺ 回到普通态 |
| 误删了 | 底部弹出的 toast 里点「撤销」 |
| 回顾哪天干了什么 | 顶栏日历图标：月历上点任意一天 |
| 优先级徽标看不懂含义 | hover 分区徽标临时看全名；双击徽标切常显/精简模式 |
| 移动整个看板 | 拖顶栏 |
| 钉在最上层 | 顶栏图钉图标 |
| 调整窗口大小 | macOS：拖动窗口**边缘或四角**（最小 320×480，尺寸会记住） |
| 检查新版本 | **双击左上角 logo** → 检查更新 |
| 昨天完成的事 | 次日起自动从面板隐去；历史在日历里看 |
| 暂时收起 | 顶栏收起按钮 → 迷你胶囊 |

界面跟随系统深浅色外观，笔记数据实时落盘，重启电脑一切都在。

## 数据与隐私

- 笔记内容**仅存本地文件**，不上传、不联网同步、绝不出现在任何上报中
- 为持续迭代产品，应用会匿名上报使用统计（随机编号、版本、语言、使用行为），**不含任何笔记内容**，无法定位到个人
- 笔记数据位置：
  - macOS: `~/Library/Application Support/Mark it!/markit-notes.json`
  - Windows: `%APPDATA%\Mark it!\markit-notes.json`
- 备份 = 复制这个文件；迁移到新电脑 = 把它拷过去

## 从源码运行

```bash
git clone https://github.com/tangchauyi/markit.git
cd markit
npm install
npm start          # 开发运行
npm run dist       # 打 macOS DMG
npm run dist:win   # 打 Windows NSIS 安装包
```

依赖 Node.js ≥ 18；`.selftest/` 内含 300+ 条行为的自测脚本（`node .selftest/v19.js`）。

界面语言跟随系统：简体中文 / 繁體中文 / English。

## 技术栈

Electron + 原生 JS（零框架零构建，renderer 单文件可直接读）。
主进程负责无边框窗口与文件持久化，渲染层负责看板交互，设计规范见 `design.md`。
